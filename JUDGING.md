# Judge path

## Stage-one viability

- Track: Grafana.
- Public product, real FFmpeg pipeline, Google ADK/Gemini, and official Grafana MCP runtime are live.
- The official MCP performs PromQL, LogQL, Tempo, and human-approved annotation operations against the dedicated stack.
- The delivery receiver is explicitly simulated; pipeline measurements are real.

## Four equal judging criteria

| Criterion | Inspect this | What it proves |
|---|---|---|
| Technological Implementation | Run **Judge proof**, inspect Grafana evidence and trace | Real media execution, exact three-threshold gate, request-bound MCP evidence, three ADK roles, Firestore state |
| Design | Delivery board in Plain and Technical modes | One operator path from risk to evidence to proposal to approval |
| Potential Impact | Six-hour constructed lead-time case and controlled failure run | Small delivery teams can see contractual jeopardy before a binary deadline miss |
| Quality of Idea | Deterministic schedule budget plus agent observability | Uses Grafana as the agent's operational sense, not merely as an after-the-fact dashboard |

## Two-minute test

1. Press **Run judge proof** and allow three real observation windows.
2. Confirm the gate reaches `at_risk` only after all three thresholds pass.
3. Inspect the ADK report: exact bound PromQL, delivery-scoped Loki, and the recorded Tempo trace must be visible.
4. Approve a remediation and confirm the Grafana annotation is written only after approval.
5. Open `/health` and the live Grafana dashboard.

No agent can create jeopardy, change a contractual date, or execute remediation. Benchmark fixtures are small engineering evidence, not a production SLO study.
